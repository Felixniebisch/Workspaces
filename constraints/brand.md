# Brand rules

## Brand name

GEM-example

## Colors

| Name | Hex | Use for |
|---|---|---|
| Primary | #2E6061 | Titles and key elements |
| Secondary | #50453E | Supporting elements and panels |
| Accent | #837651 | Highlights and call-outs |

## Fonts

- **Headings:** Abril Fatface
- **Body:** Lato

## Layout style

Professional. Every component has square corners, with no rounded corners. Copy is high contrast only: near-white on the dark brand colors, near-black on light backgrounds. Every heading is accompanied by a subheader. Make sure that the body section below the header component has everything centered. If it's only one line of text, it should sit within the middle of this section.

## Logo
